## Taxonomy

- `PUBLIC`: deliberately unauthenticated and limited to a documented public/read-only, disabled, or inert contract.
- `AUTHENTICATED`: server-verified identity is required.
- `OWNER`: authenticated identity is re-applied to the referenced creator resource.
- `ENTITLED`: authoritative subscription/entitlement state is required.
- `ADMIN`: hardened operator identity is required.
- `SCHEDULER_SECRET`: fail-closed scheduled-caller secret is required.
- `WEBHOOK_SIGNATURE`: provider signature over the raw request is required.
- `OAUTH_CALLBACK`: state/PKCE and callback-flow authenticity is required.
- `INTERNAL_CONTROLLED`: activation, confirmation, operator-secret, retired, or otherwise non-public control boundary is required.
